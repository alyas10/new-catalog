#### **Часть 1: Реализация** `CollectionType<T>`

Создайте обобщённый класс `StudentGradeCollection<T>` на основе `Queue<T>` для управления очередью оценок студента.

**Требования к классу:**

-  **Конструкторы:**

   -  Пустой конструктор

   -  Конструктор с параметром `IEnumerable<T>` для первоначального заполнения

-  **Методы:**

   -  `Enqueue(T item)` -- добавить оценку в конец очереди

   -  `Dequeue()` -- извлечь оценку из начала очереди

   -  `Peek()` -- посмотреть первую оценку без извлечения

   -  `Clear()` -- очистить очередь

-  **Индексатор:**

   -  `[int index]` -- доступ к оценке по индексу (0 -- первая добавленная оценка). Реализовать через преобразование в массив.

-  **Свойства:**

   -  `Count` -- количество оценок (только для чтения)

   -  `Average` -- средний балл (только для чтения; возвращать 0, если очередь пуста)

-  **Перегруженные операторы:**

   -  `+` -- объединение двух очередей (сначала элементы левой очереди, затем правой)

   -  `==` -- сравнение очередей по содержимому и порядку элементов

-  **Обработка исключений:**

   -  `InvalidOperationException` при вызове `Dequeue()` или `Peek()` на пустой очереди

   -  `ArgumentOutOfRangeException` при обращении к индексатору с недопустимым индексом

   -  `ArgumentNullException` при передаче `null` в конструктор с `IEnumerable<T>`

**Структура элемента коллекции (**`Grade`**):**

```
struct Grade 
{
    public int Value;      // Оценка от 2 до 5
    public string Subject; // Предмет (например, "Математика")
    public DateTime Date;  // Дата получения оценки
}
```

#### **Часть 2: Сложные LINQ-запросы**

Создайте коллекцию `StudentGradeCollection<Grade>` из 12+ оценок одного студента.

Выполните 5 LINQ-запросов (каждый должен содержать **минимум 4 операции**):

1. **Топ-3 лучших оценок за последний месяц**\
   `Where` (оценка за последние 30 дней) -> `OrderByDescending` (по значению) -> `Select` (предмет + оценка + дата) -> `Take` (3)

2. **Анализ по предметам**\
   `GroupBy` (по предмету) -> `Select` (предмет + количество оценок + средний балл) -> `Where` (количество ≥ 3) -> `OrderByDescending` (по среднему баллу)

3. **Прогресс обучения**\
   `OrderBy` (по дате) -> `Select` (индекс + оценка) -> `Skip` (2) -> `Take` (5) -> `Average` (средний балл за период)

4. **Проверка успеваемости**\
   `Any` (есть ли оценка «2») -> `All` (все ли оценки ≥ 3) -> `Where` (оценки ≥ 4) -> `Select` (предмет) -> `Distinct`

5. **Детализация по датам**\
   `Where` (оценка = 5) -> `OrderBy` (по дате) -> `Select` (новый анонимный объект: \{ Дата, Предмет, Оценка }) -> `ToList`
